# 公開整備チェック表（テンプレート）

使い方: 本ファイルを対象リポジトリの `docs/audit/polish-<repo-slug>.md` へ複製し、ヘッダと各行を記録する。判定は「合格」「不合格」「該当なし」「未確認」のいずれかとする。手順の定義は [PUBLIC_REPO_POLISH_PLAYBOOK.md](PUBLIC_REPO_POLISH_PLAYBOOK.md) を正とする。
