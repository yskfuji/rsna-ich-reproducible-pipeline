# RSNA ICH 公開スナップショット  `rsna-ich-v1.0-interview`

> これは過去の面接レビュー用スナップショットである。現行のポートフォリオ用スナップショットは `v0.6.0-rsna` である。

## 目的

採用選考や外部レビューで安定して確認するための公開スナップショットである。

## スナップショットの位置づけ

外部レビュー向けの固定スナップショットである。

## レビュー開始時の導線

- `README_ja.md`: リポジトリ全体の概要と課題要約
- `docs/reproducibility_checklist_ja.md`: 外部レビュー向けの確認項目と合格条件
- `AUDIT_MAP.md`: 主要な公開成果物や実行コマンドの所在
- `docs/api_demo_ja.md`: 公開 API 用スキーマと起動手順

## 再現対象の範囲

- RSNA 頭蓋内出血の分類ワークフロー
- 検査単位のグループ分割とリーク監査フック
- 再現しやすい学習・評価コマンド
- 校正と不確実性のレポート
- `ich_classification` 向けの公開 FastAPI デモ用スキーマ

## このスナップショットの主な強み

- 監査しやすい文書構成
- 再現性成果物 `meta.json`、`log.jsonl`、`split_stats` の整理
- グループ分割の検証と事前の重複検査
- `any` ラベルに対する不確実性・校正評価
- 将来の MLflow 連携サービングにつなげやすい API 拡張点

## 既知の制約

- 機微な医療データは同梱しない。
- GitHub Release の本文は本原稿ファイルと同期する。
- 簡易動作確認はリポジトリが正しく動くかを確かめるためのものであり、モデル品質そのものを保証するものではない。
- FastAPI デモは、まだ実際のチェックポイントや MLflow の model URI を直接読み込む構成ではない。
