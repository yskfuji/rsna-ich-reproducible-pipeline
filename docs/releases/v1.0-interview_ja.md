# RSNA ICH 公開スナップショット  `rsna-ich-v1.0-interview`

> これは過去の面接レビュー用スナップショットです。現行のポートフォリオ用スナップショットは `v0.6.0-rsna` です。

## 目的
採用選考や外部レビューで安定して確認してもらうための公開スナップショットです。

## スナップショットの位置づけ
外部レビュー向けの固定スナップショットです。

## レビュー開始時の導線
- README: リポジトリ全体の概要とタスク要約
- docs/reproducibility_checklist.md: 外部レビュー向けの確認項目と合格条件
- AUDIT_MAP.md: 主要な公開成果物や実行コマンドの所在
- docs/api_demo.md: 公開 API 用スキーマと起動メモ

## 再現対象の範囲
- RSNA 頭蓋内出血分類ワークフロー
- study 単位のグループ分割とリーク監査フック
- 再現しやすい学習 / 評価コマンド
- 校正と不確実性のレポート
- `ich_classification` 向けの公開 FastAPI デモ用スキーマ

## このスナップショットの主な強み
- 監査しやすいドキュメント構成
- 再現性アーティファクト `meta.json`、`log.jsonl`、`split_stats` の整理
- グループ分割の検証と事前の重複チェック
- `any` ラベルに対する不確実性 / 校正評価
- 将来の MLflow 連携サービングにつなげやすい API 拡張点

## 既知の制約
- 機微な医療データは同梱していません
- GitHub Release の本文はこの原稿ファイルと同期しています
- 簡易動作確認はリポジトリが正しく動くかを確かめるためのものであり、モデル品質そのものを保証するものではありません
- FastAPI デモは、まだ実際のチェックポイントや MLflow の model URI を直接読み込む構成ではありません
