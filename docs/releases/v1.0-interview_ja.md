# RSNA ICH 公開スナップショット  `rsna-ich-v1.0-interview`

## 目的
採用選考や外部レビューで安定して確認してもらうための公開スナップショットです。

## スナップショットの位置づけ
安定版のレビュー用構成です。

## レビュー開始時の導線
- README: リポジトリ全体の概要とタスク要約
- docs/reproducibility_checklist.md: 外部レビュー向けの確認項目と合格条件
- AUDIT_MAP.md: 主要な公開成果物や実行コマンドの所在
- docs/api_demo.md: 公開 API スキーマと起動メモ

## 再現対象の範囲
- RSNA 頭蓋内出血分類ワークフロー
- study 単位のグループ分割とリーク監査フック
- 再現しやすい学習 / 評価コマンド
- 校正と不確実性のレポート
- `ich_classification` 向けの公開 FastAPI デモスキーマ

## このスナップショットの主な強み
- 監査しやすいドキュメント構成
- 再現性アーティファクト `meta.json`、`log.jsonl`、`split_stats` の整理
- グループ分割の検証と事前の重複チェック
- `any` ラベルに対する不確実性 / 校正評価
- 将来の MLflow 連携サービングへつなげやすい API 拡張点

## 既知の制約
- 保護対象の医療データは同梱していません
- GitHub Release の本文はこの原稿ファイルと同期しています
- 簡易動作確認はリポジトリ配線の確認用であり、モデル品質そのものを保証するものではありません
- FastAPI デモはまだ実チェックポイントや MLflow model URI を直接読み込む構成ではありません
