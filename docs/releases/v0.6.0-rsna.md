# RSNA ICH public snapshot — `v0.6.0-rsna`

## Purpose
A portfolio snapshot that extends the public RSNA workflow from experiment tracking and API review to registry-ready model promotion.

## Snapshot type
Current portfolio release.

## Suggested review order
1. Start with the README for the overall picture and task summary.
2. Use docs/reproducibility_checklist.md for the review checkpoints, suggested order, and pass criteria.
3. Use AUDIT_MAP.md and docs/api_demo.md to locate the main artifacts, API demo notes, and commands.

## Reviewer starting points
- README: repository overview and task summary
- docs/reproducibility_checklist.md: external review checklist, suggested review order, and pass criteria
- AUDIT_MAP.md: where major public artifacts and commands live
- docs/api_demo.md: public API schema and startup notes
- core/pipeline/tools/register_model.py: registry-ready bundle creation and promotion-criteria entrypoint

## Reproduced scope
- RSNA intracranial hemorrhage classification workflow
- Study-level group split and leakage audit hooks
- Reproducible training / evaluation commands
- Calibration, uncertainty reporting, and benchmark-summary table
- Public FastAPI demo schema for `ich_classification`
- Registry-ready model bundle creation from completed runs
- Optional MLflow Registry handoff with promotion-criteria evaluation and alias updates

## Main strengths in this snapshot
- Audit-ready documentation
- A clear review path that starts from the checklist and reduces missed steps
- Logged reproducibility artifacts (`meta.json`, `log.jsonl`, `split_stats`)
- Group-split validation and pre-split de-dup checks
- Uncertainty / calibration evaluation for the `any` label
- Clear API-facing extension point plus MLflow Registry promotion path
- Configurable promotion criteria such as weighted logloss thresholds

## Known limitations
- Protected medical data is not bundled
- GitHub Release text is mirrored from this source file
- Smoke test validates repository wiring, not full model quality
- The FastAPI demo does not yet load a real checkpoint or MLflow model URI
- Promotion criteria are evaluated on the latest logged metrics and still require human-defined thresholds
