# RSNA ICH 公開スナップショット  `v0.5.0-rsna`

## 目的
公開中のドキュメント、ベンチマーク要約表、API デモ解説を反映した、現行のポートフォリオ用スナップショットです。

## スナップショットの位置づけ
現行のポートフォリオ公開版です。

## レビュー開始時の導線
- README: リポジトリ全体の概要とタスク要約
- docs/reproducibility_checklist.md: 外部レビュー向けの確認項目と合格条件
- AUDIT_MAP.md: 主要な公開成果物や実行コマンドの所在
- docs/api_demo.md: 公開 API スキーマと起動メモ

## 再現対象の範囲
- RSNA 頭蓋内出血分類ワークフロー
- study 単位のグループ分割とリーク監査フック
- 再現しやすい学習 / 評価コマンド
- 校正、不確実性レポート、ベンチマーク要約表
- `ich_classification` 向けの公開 FastAPI デモ用スキーマ

## このスナップショットの主な強み
- 監査しやすいドキュメント構成
- 再現性アーティファクト `meta.json`、`log.jsonl`、`split_stats` の整理
- グループ分割の検証と事前の重複チェック
- `any` ラベルに対する不確実性 / 校正評価
- 将来の MLflow 連携サービングにつなげやすい API 拡張点

## 既知の制約
- 機微な医療データは同梱していません
- GitHub Release の本文はこの原稿ファイルと同期します
- 簡易動作確認はリポジトリが正しく動くかを確かめるものであり、モデル品質そのものを保証するものではありません
- FastAPI デモは、まだ実際のチェックポイントや MLflow の model URI を直接読み込む構成ではありません
