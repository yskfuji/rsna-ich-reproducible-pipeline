# RSNA ICH 公開スナップショット  `v0.6.0-rsna`

## 目的
公開 RSNA ワークフローの MLOps ストーリーを、実験追跡と API デモから registry-ready なモデル昇格段階まで進めたスナップショットです。

## スナップショットの位置づけ
現行のポートフォリオ公開版です。

## 最初に見ると分かりやすい順番
1. README で全体像とタスク要約をつかむ
2. docs/reproducibility_checklist_ja.md でレビュー観点と確認手順を追う
3. AUDIT_MAP.md と docs/api_demo.md で成果物、API デモ、主要コマンドの所在を確認する

## レビュー開始時の導線
- README: リポジトリ全体の概要とタスク要約
- docs/reproducibility_checklist_ja.md: 外部レビュー向けの確認項目、確認順序、合格条件
- AUDIT_MAP.md: 主要な公開成果物や実行コマンドの所在
- docs/api_demo.md: 公開 API スキーマと起動メモ
- core/pipeline/tools/register_model.py: registry-ready なバンドル作成と昇格条件評価の入口

## 再現対象の範囲
- RSNA 頭蓋内出血分類ワークフロー
- study 単位のグループ分割とリーク監査フック
- 再現しやすい学習 / 評価コマンド
- 校正、不確実性レポート、ベンチマーク要約表
- `ich_classification` 向けの公開 FastAPI デモ用スキーマ
- 学習済み run からの registry-ready なモデル登録バンドル生成
- 昇格条件の判定と MLflow Registry alias 更新を伴う任意の登録連携

## このスナップショットの主な強み
- 監査しやすいドキュメント構成
- 日本語チェックリストからレビューを始められるため、確認の抜け漏れを減らしやすい
- 再現性アーティファクト `meta.json`、`log.jsonl`、`split_stats` の整理
- グループ分割の検証と事前の重複チェック
- `any` ラベルに対する不確実性 / 校正評価
- API デモの拡張点に加えて MLflow Registry への昇格経路を提示
- weighted logloss などを使った昇格条件を設定可能

## 既知の制約
- 機微な医療データは同梱していません
- GitHub Release の本文はこの原稿ファイルと同期します
- 簡易動作確認はリポジトリが正しく動くかを確かめるものであり、モデル品質そのものを保証するものではありません
- FastAPI デモは、まだ実際のチェックポイントや MLflow の model URI を直接読み込む構成ではありません
- 昇格条件は最新のログ指標に対して評価するため、最終判断には人手でのしきい値設計が必要です
