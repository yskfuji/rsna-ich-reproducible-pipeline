# RSNA ICH public snapshot — `v0.5.0-rsna`

## Purpose
A portfolio snapshot that reflects the current public documentation, benchmark-summary table, and API-demo notes.

## Snapshot type
Current portfolio release.

## Reviewer starting points
- README: repository overview and task summary
- docs/reproducibility_checklist.md: external review checklist and pass criteria
- AUDIT_MAP.md: where major public artifacts and commands live
- docs/api_demo.md: public API schema and startup notes

## Reproduced scope
- RSNA intracranial hemorrhage classification workflow
- Study-level group split and leakage audit hooks
- Reproducible training / evaluation commands
- Calibration, uncertainty reporting, and benchmark-summary table
- Public FastAPI demo schema for `ich_classification`

## Main strengths in this snapshot
- Audit-ready documentation
- Logged reproducibility artifacts (`meta.json`, `log.jsonl`, `split_stats`)
- Group-split validation and pre-split de-dup checks
- Uncertainty / calibration evaluation for the `any` label
- Clear API-facing extension point for future MLflow-backed serving

## Known limitations
- Protected medical data is not bundled
- GitHub Release text is mirrored from this source file
- Smoke test validates repository wiring, not full model quality
- The FastAPI demo does not yet load a real checkpoint or MLflow model URI
